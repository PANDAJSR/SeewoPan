# SeewoPan

SeewoPan 是一个基于 Flutter 开发的「希沃品课云盘」第三方客户端。

## 项目状态

- 设计语言：Material Design 3
- 目标平台：Android、iOS、Web、macOS、Windows、Linux

## 开发环境

- Flutter：建议使用 stable 渠道
- Dart：随 Flutter SDK 版本

## 快速开始

```bash
flutter pub get
flutter run
```

如果你的 `flutter` 未加入 PATH，可使用绝对路径，例如：

```bash
~/flutter/bin/flutter pub get
~/flutter/bin/flutter run
```

## 项目结构

- `lib/`：应用源码
- `test/`：测试代码
- `android/`、`ios/`、`web/`、`macos/`、`windows/`、`linux/`：各平台工程

## 说明

本项目为第三方客户端，和希沃官方无隶属关系。
